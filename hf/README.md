# REVE Embedding Atlas Demo

This public dataset contains deterministic synthetic EEG and MEG window metadata for the
[REVE Embedding Atlas](https://jonathanlys01.github.io/reve-atlas/) frontend smoke test.

The coordinates, reconstruction losses, and metadata are synthetic. They are not research results and contain no
participant data. The real projection pipeline will replace this file in a later milestone.
